# ShelfSwap Genie

A local prototype for retail planogram experiments: swap two products or optimize the entire shelf, then compare projected weekly revenue, gross-margin contribution and units.

## What it includes

- **Interactive 3D shelf** rendered with Three.js; product positions animate after a scenario is applied.
- **Blender-authored `.glb` shelf asset** in `public/assets/shelf-demo.glb` (generated by `scripts/create_shelf.py`).
- **Backend simulation API**: `POST /api/simulate` receives the current shelf and two product IDs; `POST /api/optimize` evaluates product/slot assignments and returns the highest projected revenue arrangement.
- **Explainable prototype logic**: slot visibility and snack adjacency are explicit demo assumptions. It is not connected to Databricks Genie or real point-of-sale data.

## Run

```bash
npm install
npm run model
npm start
# open http://localhost:4174
```

## Test

```bash
npm test
```

## Data and production boundary

All products, revenue figures and projected KPIs are fictional demonstration data. The optimizer uses transparent deterministic rules so judges can audit its result. A production integration would replace the rule model with governed historical sales, inventory, promotion, price, facings and store-layout data, then call Genie for grounded natural-language explanations.

## 3D product assets

The included GLB is original geometry created by the Blender script. If replacing it with Sketchfab product models, only use files whose downloadable license and brand-use rights are explicitly approved for the competition; keep attribution/license metadata with each asset.
